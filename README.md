# GBDMARKET

Actúa como un equipo experto en UX/UI, Marketing Digital, Comercio Electrónico, Desarrollo Web y Automatización Comercial.

Diseña y desarrolla una página web moderna, rápida, responsive y optimizada para SEO para las unidades de negocio Línea Blanca y Bordados de la Cooperativa Gladys B. de Ducasa R.L.

Herramienta de generación de cotizaciones.

Administrador de inventario.
Plataforma para exhibir servicios de bordados personalizados.
